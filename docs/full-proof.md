## §0 约定与记号

所有图有限、简单、无向、连通。`d(x,y)` = 距离;`ecc(x) = max_y d(x,y)`;
`r = min_x ecc(x)`;`δ = 最小度`;`t = max{|S| : G[S] 是树}`。
割点:删去后图不连通的点;非割点(ncv):删去后图仍连通的点。
UEP:`x` 是 `c` 的唯一离心点(UEP),记 `UEP(c,x)`,指
`d(c,x) = ecc(c)` 且 `∀y ≠ x, d(c,y) < ecc(c)`。
半径只对连通图有定义;G−v 连通时 r(G−v) 才有意义。

全文假设 `|V(G)| ≥ 2`。叶子 = 1 度点。

## §1 初等引理层(全部 ✅)

**F1(测地线是诱导路).** 任何最短路(测地线)的导出子图恰是该路径本身。
证:若导出子图含连接非相邻路内顶点的弦边,用它短路与测地性矛盾。∎

**F2(rad ≤ diam;t ≥ r+1).** `rad(G) ≤ diam(G)`,且 `t(G) ≥ diam+1 ≥ r+1`。
证:rad = min ecc ≤ 任意点 eccentricity ≤ diam。取距离为 diam 的点对,
其测地线由 F1 是诱导路,阶 diam+1。∎

**F3(删一点半径至多降 1).** G 连通,v ∈ V(G),G−v 连通非空 ⇒ `r(G) ≤ r(G−v)+1`。
证:取 G−v 的中心 c′,ρ = r(G−v)。对 x ≠ v:`d_G(c′,x) ≤ d_{G−v}(c′,x) ≤ ρ`
(超图距离 ≤ 子图距离)。v 在 G−v 中有邻点 w(G−v 非空 + G 连通),
`d_G(c′,v) ≤ 1 + d_G(c′,w) ≤ ρ+1`。故 `ecc_G(c′) ≤ ρ+1`。∎

**F4(路径不可穿过叶子).** z 是叶时,任何两端 ≠ z 的简单路径不含 z。
证:经过 z 的路径须进出 z 各一次,而 z 度数为 1。∎
推论(删叶保距):删叶后其余点间距离不变;中心 c 到其余点的距离不变。

**F5(删叶不增半径).** G 连通,z 是叶,|V| ≥ 3 ⇒ `r(G−z) ≤ r(G)`。
证:取 G 的中心 c。z 是叶 ⇒ z ≠ c(由 F8,z 不可能中心)。对每个 x ≠ z:
`d_{G−z}(c,x) = d_G(c,x)`(F4)≤ `ecc_G(c) = r`。故 `r(G−z) ≤ ecc_{G−z}(c) ≤ r`。∎
(结合 F3:`r(G)−1 ≤ r(G−z) ≤ r(G)`。)

**F6(叶非中心).** |V| ≥ 3 时叶 z 满足 `ecc(z) = 1 + ecc(p(z)) ≥ 1 + r > r`。∎

**F7(UEP ⇒ 降半径;判据易半).** 若 `UEP(c,v)` 且 c 中心,则 G−v 连通且
`r(G−v) = r−1`。(不需要假设 v 非割点。)
证:对 x ≠ v:任何经 v 的 c–x 路长 ≥ `d(c,v) + d(v,x) ≥ r+1 > r−1 ≥ d(c,x)`
(UEP 定义给出严格上界),故 c–x 最短路全部避开 v,`d_{G−v}(c,x) = d_G(c,x) ≤ r−1`。
于是 G−v 中每点都连到 c ⇒ 连通,且 `ecc_{G−v}(c) ≤ r−1`,`r(G−v) ≤ r−1`;
反向由 F3。∎

**F8(降半径 ⇒ UEP;判据"难半",实为初等).** G 连通,v 非割点,`r(G−v) = r−1`
⇒ 存在中心点 c 使 `UEP(c,v)`。
证:取 c 为 G−v 的中心(`ecc_{G−v}(c) = r−1`)。对 x ≠ v:
`d_G(c,x) ≤ d_{G−v}(c,x) ≤ r−1`。而 `ecc_G(c) ≥ r(G) = r`,故 `d_G(c,v) ≥ r`。
又 v 在 G−v 中有邻点 w,`d_G(c,v) ≤ 1 + d_G(c,w) ≤ 1 + (r−1) = r`。
故 `d_G(c,v) = r = ecc_G(c)`,c 中心,v 是 c 的唯一离心点。∎

**F9(一点至多一个 UEP).** 若 `UEP(c,x)` 且 `UEP(c,x′)`,则 x = x′。
证:x ≠ x′ 时 UEP(c,x) 给出 `d(c,x′) < ecc(c)`,与 UEP(c,x′) 的取等矛盾。∎

**F10(每个连通图有 ≥ 2 个非割点).** 取最长路 v₁…v_k,则 v₁、v_k 非割点。
证:对任意 x ≠ v₁,取 x–v₁ 测地线 x₀…x_m = v₁;x_{m−1} 是 v₁ 的邻点,故在
最长路上(最长路端点的一切邻点都在路上),x_{m−1} = v_i(i ≥ 2);x₀…x_{m−1}
避开 v₁,再沿路 v_i→v_{i−1}→…→v₂(避开 v₁)接上,故 G−v₁ 中每点可达 v₂。∎

**F11(叶的邻点是割点).** |V| ≥ 3,叶 u、p(u) = a ⇒ a 是割点。
证:G−a 中 u 孤立,而 G−a 还有其他顶点。∎

**F12(|V| 下界).** r ≥ 2 ⇒ |V| ≥ 4。
证:r ≥ 2 ⇒ 无泛在点;n = 3 只有 P₃、K₃,二者有泛在点,r = 1。∎

**F13(计数).** 对 s,ℓ ≥ 1:`(s+1)(ℓ+1) ≥ 2(s+ℓ)`,因为差 = `(s−1)(ℓ−1) ≥ 0`。∎

**F14(诱导树遗传).** v ∈ V(G) ⇒ `t(G−v) ≤ t(G)`。
证:S ⊆ V(G−v) 时 `(G−v)[S] = G[S]`,故 G−v 的诱导树也是 G 的诱导树。∎

**F15(辅助引理;Lean 已证:`degree_one_neighbor_of_all_other`).** D 有限简单图,
`δ(D) ≥ 1`,a ∈ V(D),且每个 v ≠ a 都有 1 度邻点 ⇒ a 也有 1 度邻点。
证:反设 a 的邻点都非 1 度。取 x ∈ N(a)(δ ≥ 1);x ≠ a 且 `deg(x) ≥ 2`。
由假设(x ≠ a)取 x 的 1 度邻点 y;y 的唯一邻点是 x。若 y ≠ a,对 y 用假设:
其 1 度邻点只能是 x,得 `deg(x) = 1`,矛盾。故 y = a,即 `deg(a) = 1` 且 a ∼ x。
由 `deg(x) ≥ 2` 取 z ∈ N(x) ∖ {a}。z ≠ a 有 1 度邻点 w:w ≠ a(a 只邻 x ≠ z),
w ≠ x(否则 deg(x) = 1)。w 是叶,唯一邻点是 z;对 w(w ≠ a)用假设得
`deg(z) = 1`;但 z 同时邻 x 与 w 且 x ≠ w,`deg(z) ≥ 2`,矛盾。∎

## §2 有根 Chung 引理(✅ 完整,含原论文隐式步骤 (a)(b) 的补全;✅ Lean 已证:`RootedChung.rooted_chung`——`chung_context` 距离账 + `chung_chords` 七条弦排除 + `rooted_chung_flat` 无弦拼接 + `rooted_chung_chord` 三段拼接 + 派发,Run #124 全绿)

1. 取 F−a 的中心 v₀:`ecc_{F−a}(v₀) = r−1`(v₀ ≠ a)。
2. 对每个 x ≠ a:`d_F(v₀,x) ≤ d_{F−a}(v₀,x) ≤ r−1`。
3. **d_F(v₀,a) = r。**
   (≥)`ecc_F(v₀) ≥ r(F) = r`,而其余点 ≤ r−1,迫使 `d(v₀,a) ≥ r`;
   (≤)a 有邻点 w(F 连通、|V| ≥ 2),w ≠ a,故 `d(v₀,a) ≤ 1 + d(v₀,w) ≤ r`。
   〔原论文隐式步骤 (a) 的补全:论文只写了 (≥) 方向。〕
4. 固定 v₀–a 测地线 `v₀, v₁, …, v_r = a`;由 F1 它是诱导的,且 `d(v₀,v_j) = j`。
5. `ecc_F(v₂) ≥ r`(任何点 ecc ≥ 半径),故存在 w 使 `d_F(v₂,w) ≥ r`。
   w ≠ a,因为 `d(v₂,a) = r−2 < r`。
6. `d_F(v₀,w) ≥ d(v₂,w) − d(v₀,v₂) ≥ r−2`,且由 2,`d_F(v₀,w) ≤ r−1`(w ≠ a)。
   取 v₀–w 测地线 `P = p₀, …, p_m`(p₀ = v₀,p_m = w,`m = d(v₀,w) ∈ {r−2, r−1}`)。
   P 由 F1 诱导。
7. **弦排除.**
   (7a) 对 j ≥ 2,任何 p_i 都不与 v_j 相邻:若不然,
   `m = d(v₀,w) = d(v₀,p_i) + d(p_i,w) ≥ (j−1) + (d(v_j,w) − 1)`,而
   `d(v_j,w) ≥ d(v₂,w) − d(v₂,v_j) ≥ r − (j−2) = r−j+2`,合计 `m ≥ r`,与 m ≤ r−1 矛盾。
   (7b) v₁ 与 p_i(i ≥ 2)不相邻:若不然,沿 v₂→v₁→p_i→(沿 P)→w 得
   `d(v₂,w) ≤ 1 + 1 + (m−i) ≤ m ≤ r−1 < r`,矛盾。
   (7c) v₁ 与 p₁ 可能相邻——**若相邻,则强制 m = r−1**:
   同 (7b) 的路长论证(i = 1)给出 `r ≤ d(v₂,w) ≤ m+1`,故 m ≥ r−1,结合 m ≤ r−1。
   〔原论文隐式步骤 (b) 的补全:论文直接说"删 v₀ 后仍 ≥ 2r−1",
   实际上需要例外弦迫使总点数为 2r。〕
8. 拼接 `Q = v_r, v_{r−1}, …, v₀, p₁, …, p_m`。内部:v 段测地线诱导、P 诱导、
   交叉弦被 (7a)(7b) 排除;相邻衔接边都是真实边。故 Q 是诱导路径,
   阶 `(r+1) + m`,且 a = v_r ∈ Q。
9. 若 v₁–p₁ 不是弦:Q 诱导,阶 ≥ `2r−1`,完成。
10. 若 v₁–p₁ 是弦:由 (7c),m = r−1,阶 = 2r。删去 v₀ 得
    `Q′ = v_r, …, v₁, p₁, …, p_m`:衔接边 v₁–p₁ 恰是那条弦,其余内部诱导性同上
    (v₁ 与 p_i(i ≥ 2)的弦已被 (7b) 排除),阶 `2r−1`,仍含 a。∎

(即 V 分成共轭对 {v, f(v)},d = r,且每点与其配点互为唯一离心点)。
证:(1)⇒(2):每点 v 非割点且降半径,F8 给中心 c_v 使 UEP(c_v,v)。
映射 f: v ↦ c_v 由 F9 单射,故 |V| ≤ |C| ≤ |V|,得 C = V(自中心)且 f 是
双射。f(v) ≠ v(d = r ≥ 1)。f² = id:f²(v) 与 v 都距 f(v) 为 r
(前者因 UEP(f²(v), f(v)) 即 d(f²(v),f(v)) = r),由 f(v) 离心点唯一性
f²(v) = v。又 UEP(v, f(v)) 由 UEP(f(f(v)), f(v)) = UEP(v, f(v)) 读出。
(2)⇒(1):d(v,f(v)) = ρ 与 v 无关(f² = id),且 x ≠ f(v) ⇒ d(v,x) ≤ ρ−1,
故每点离心率 = ρ,r(B) = ρ。删 v:任何 f(v)–x 路过 v 则长 ≥ ρ+1 > ρ−1 ≥
d(f(v),x),故最短路避开 v,B−v 连通且 ecc_{B−v}(f(v)) ≤ ρ−1;反向 F3。
∎

**3.7c(向下归纳:G_i = S_{k−i}(B)).** ✅ 对 i = k,…,0 成立
G_i = S_{k−i}(B)。归纳步:设 G_{i+1} = S_m(B)(m = k−i−1 ≥ 0),证
G_i = S_{m+1}(B)。
准备:G_i = G_{i+1} + 叶集,每叶的母点 ∈ G_{i+1}(母子同为 G_{i+1}−叶将迫使
G_i = K₂,与 r(G_i) ≥ 2 矛盾),且每点至多一个叶(3.6b 用于 G_i)。记
P = 有叶母点集。需证 P = S_m(B) 的尖端集(深度恰 m 的 |B| 个点)。
(α) **P ⊇ 全部尖端。** r(G_i) = r(G_{i+1})+1 = r(B)+m+1,故每个 z ∈ B 满足
`ecc_{G_i}(z) ≥ r(B)+m+1`。而 S_m(B) 部分给 `d(z,x) ≤ r(B)+m`(x 在 b′ 支
深度 j:d(z,x) = d(z,b′)+j ≤ r(B)+m,B 自中心),故必有 p ∈ P 使
d(z,p) ≥ r(B)+m;又 d(z,p) ≤ r(B)+depth(p) ≤ r(B)+m,故 d(z,p) = r(B)+m,
其解唯一:p = f(z) 支的尖端 w_z(B 的离心点唯一,3.7b)。f 满 ⇒ 全部尖端 ∈ P。
(β) **P ⊆ 尖端。** 反设 p ∈ P 在深度 j < m,叶 u ∼ p。u 是 G_i 的非割点,
vrd + F8 给中心 c 使 `UEP(c,u)`:`d(c,u) = r(B)+m+1`,故 `d(c,p) = r(B)+m`。
c 不是叶(F6)。定位 c:
 - c ∈ B:d(c,p) ≤ r(B)+j ≤ r(B)+m−1,太小;
 - c 在 p 同支(深度 d″):d(c,p) = |d″−j| ≤ m < r(B)+m,太小;
 - c 在异支 b″(深度 d″):p 所在支的尖端 w(深度 m)满足
   `d(c,w) = d″+d(b″,b)+m = d(c,p)+(m−j) ≥ r(B)+m+1 = ecc(c)`,
   故 d(c,w) = ecc(c),由 UEP(c,u) 唯一性 w = u;但 w ∈ V(G_{i+1}) 而
   u ∉ V(G_{i+1}),矛盾。
∎
(附:G_i 中非 B 顶点的 G-边恰为"祖先边"{x, π(x)},B 与悬挂部分之间的边
亦然——这在 (β) 的距离计算里用到"支=悬挂路"。)

**3.7d(结论).** ✅ G = G₀ = S_k(B),`r(G) = r(B)+k`(链上半径逐层降 1)。
推论 **3.B**:t(G) ≥ 2r(G)。
证:B 中取测地线 Q(阶 ≥ r(B)+1,F1/F2);Q 的顶点连同各支全长悬挂路
构成诱导树,阶 ≥ `(r(B)+1)(k+1) ≥ 2(r(B)+k) = 2r`(F13,s := r(B) ≥ 1)。∎
(iii) B = K₂ 无需特殊处理:刻画 (3.7b) 对 K₂ 成立(f = 对换,r = 1),
F13 在 s = 1 时取等,P_{2k+2} 的 t = 2r 恰好贴合。∎

## §4 叶子引理与最终定理(✅ 完整组装——数学证明就此闭合)

**定理 4.1(叶子引理).** G 有限连通且有叶 u,则 `t(G) ≥ 2r(G)`。

**证明.** 反设引理不真,取**极小阶反例** G:G 连通、有叶、`t(G) < 2r(G)`,
而任何顶点数更少的连通有叶图都满足引理。固定叶 u,记 a = p(u)(唯一邻点),
r := r(G)。

**第 0 步(小情形与设置).** 若 r = 1:边 ua 本身是 2 = 2r 个点的诱导树,
与 t(G) < 2r 矛盾。故 **r ≥ 2**,从而 |V(G)| ≥ 4(F12),且 a 是割点(F11)。

**Claim 1.** 对每个非割点 v ≠ u:`r(G−v) = r−1`。
证:v ≠ a(a 是割点而 v 非割点)。G−v 连通且 u 仍是叶。若 `r(G−v) ≥ r`:
G−v 是更小的连通有叶图,极小性给 `t(G−v) ≥ 2r(G−v) ≥ 2r`;又 t(G−v) ≤ t(G)
(F14),与 `t(G) < 2r` 矛盾。故 `r(G−v) < r`,由 F3 取等。∎

令 **H := G−u**。删叶保距(F4);u 非中心(F6,|V| ≥ 3),故 G 的中心留在
H 中且其在 H 中的离心率 ≤ r,得 `r(H) ≤ r`;若 `r(H) < r`,u 是非割点,F3 给
`r(H) = r−1`。于是

    r(H) ∈ {r−1, r}.

**Case A:r(H) = r−1.** 此时每个非割点的删除都把半径降到 r−1:u 由本 Case,
其余非割点由 Claim 1。故 G 是 vrd 且有割点 a,**由 3.B,t(G) ≥ 2r,矛盾**。

**Case B:r(H) = r.**

**(4) H 无叶。** 否则 H 是更小的连通有叶图且半径 r(H) = r,极小性给
`t(H) ≥ 2r(H) = 2r`,而 t(G) ≥ t(H)(F14),矛盾。故 **δ(H) ≥ 2**。

**Claim 2.** 对 H 的每个非割点 v ≠ a:`r(H−v) = r−1`。
证:G−v 是在连通图 H−v 上挂回叶 u(邻 a),连通,故 v 也是 G 的非割点,
Claim 1 给 `r(G−v) = r−1`。G−v 至少 3 个点,其叶 u 非中心(F6),故 G−v 的
中心都在 H−v 中;结合删叶保距(F4)得 `r(H−v) ≤ r−1`;反向由 F3
(v 在 H 非割点,r(H) = r)。∎

**Claim 3.** H 无割点。
证:反设 c 是 H 的割点。取 H 的**端块** B₀,其唯一 H-割点为 c(块-割点树的
叶块);端块内 c 以外的点都是 H 的非割点(标准块事实,见 3.4)。若 B₀ = K₂,
设 B₀ = {c,w}:w 的一切 H-边都在 B₀ 内(w 若属于其它块则为割点,与端块
只有割点 c 矛盾),故 deg_H(w) = 1,w 是叶,与 (4) 矛盾。故 |B₀| ≥ 3,B₀
2-连通,c 在 B₀ 内有 ≥ 2 个邻点;其中至多一个是 a,可取 **v ≠ a**。v 是 H 的
非割点(端块内非割点)且 deg_H(v) ≥ 2(δ(H) ≥ 2)。由 Claim 2 + F8:v 是 H
某中心点 z 的 UEP;再由 3.2(deg(v) ≥ 2):v 的一切邻点都是 H 的非割点。但
c ∼ v,故 c 非割点,与 c 是割点矛盾。∎

由 Claim 3,H 的每个点都是非割点。对每个 v ≠ a:Claim 2 + F8 给出中心 c_v
使 `UEP(c_v, v)`;不同 v 给不同 c_v(F9)。于是 n := |V(H)| 时 **H 至少有
n−1 个中心**。

**Claim 4.** H 自中心。
证:反设 b 非中心。每个 y ≠ b 是中心 ⇒ d(y,b) ≤ ecc(y) = r ⇒ d(b,y) ≤ r ⇒
ecc(b) ≤ r;又 ecc(b) ≥ r(H) = r。故 ecc(b) = r,b 中心,矛盾。∎

**辅助图 D.** V(D) = V(H),xy ∈ E(D) ⟺ d_H(x,y) = r。自中心 + 有限性 ⇒
每点都有距离恰 r 的点,故 **δ(D) ≥ 1**。对每个 v ≠ a:c_v 与 v 在 D 中相邻,
且 **deg_D(c_v) = 1**(若另有 w 与 c_v 距离 r,则违反 UEP(c_v,v) 的唯一性)。
即:每个 v ≠ a 都有 1 度邻点。由 **F15**,a 也有 1 度邻点,记 c:d_H(c,a) = r,
且 deg_D(c) = 1 说明 a 是 c 的唯一距离 r 点。c 是中心(Claim 4),故
**UEP(c, a)**(ecc(c) = r,d(c,a) = r,其余点 ≤ r−1)。

由 **F7**:`r(H−a) = r−1`(且 H−a 连通)。a 是 H 的非割点(Claim 3)。
由**引理 2.1(有根 Chung)**:H 含一条**经过 a** 的诱导路径 P,|P| ≥ 2r−1。

**收尾.** u 的唯一邻点是 a ∈ P,故 G[V(P) ∪ {u}] 的导出子图 = P 的边加
u–a 一条边,是 **阶 ≥ 2r 的诱导树**。与 t(G) < 2r 矛盾。∎

**定理 4.2(Graffiti.pc 猜想 84).** G 有限连通,|V(G)| ≥ 2,则

    2·r(G) ≤ t(G)·δ(G)(等价于 t(G) ≥ 2r(G)/δ(G))。

证:连通非平凡图 r ≥ 1、δ ≥ 1。
- **δ ≥ 2:** F2 给 t ≥ r+1,故 tδ ≥ 2(r+1) = 2r+2 > 2r。
- **δ = 1:** G 有叶,定理 4.1 给 t ≥ 2r,故 tδ = t ≥ 2r。∎
