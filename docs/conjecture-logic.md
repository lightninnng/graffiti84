## 1. 猜想的陈述

### 1.1 原始形式

West 的 Graffiti.pc 猜想目录(dwest.web.illinois.edu/regs/graffiti.html,2004 年条目)
第 84 条原文:

> **If G is connected, then t(G) ≥ 2r(G)/δ(G).**

其中(按该目录的定义):

- `t(G)`:G 的最大**诱导树**(induced tree)的顶点数;
- `r(G)`:半径,即顶点离心率的最小值;`ecc(v) = max_x d(v,x)`,`r = min_v ecc(v)`;
- `δ(G)`:最小度(目录未显式定义 δ,按标准记号取最小度)。

### 1.2 等价整数形式

对连通且 `|V(G)| ≥ 2` 的图,`δ ≥ 1`,故

    t(G) ≥ 2r(G)/δ(G)   ⟺   2·r(G) ≤ t(G)·δ(G)     (★)

(★) 是分数-free 的形式,也是 Lean 中的目标形式(`GraphConjecture84.final_arithmetic`)。
单点图 K₁ 使 δ = 0、原式无定义,故统一约定 `|V(G)| ≥ 2`(K₁ 时 (★) 两边为 0,平凡成立)。

### 1.3 紧性:为什么 δ = 1 恰好是唯一实质情形

- 路径 `P_{2r}`:δ = 1,t = 2r,此时 `2r/δ = 2r = t`,**取等**。所以 δ=1 情形不可能
  证出比 `t ≥ 2r` 更强的界,叶子引理是精确目标。
- δ ≥ 2 时右边 `2r/δ ≤ r`,门槛显著更低(见 §4,这一情形其实初等可解)。
- 一般事实:任何连通图都有 `t ≥ diam + 1 ≥ r + 1`(两端点距离为 diam 的**测地线**
  必是诱导路径——任何"弦"都会缩短它)。这给出普适下界,但对 δ=1 远不够 2r。

## 2. 证明蓝图(依 paper/graffiti84.tex)

记 `r = r(G)`。整体是按 δ 拆两支:

### 2.1 情形 δ ≥ 2(论文路线)

Erdős–Saks–Sós / Chung 定理:`t ≥ 2r − 1`。于是
`t·δ ≥ 2(2r−1) = 4r − 2 ≥ 2r`(用 r ≥ 1)。
纯算术,已在 Lean 中证出(`final_arithmetic`)。
**§4 会说明:这一支其实不需要 ESS,用测地线就够了。**

### 2.2 情形 δ = 1:叶子引理

> **叶子引理.** 有限连通图若有叶子(1 度点)`u`,则 `t(G) ≥ 2r`。

反证,取**最小阶反例** G。固定叶子 u,其唯一邻点记 a。

**准备步骤.**
- `r = 1` 时边 ua 本身是 2 = 2r 个点的诱导树,矛盾。故 `r ≥ 2`,从而 `|V| ≥ 4`(见 §6(e))。
- a 是割点:删 a 使 u 孤立(需 `|V| ≥ 3`)。
- **Claim 1**:每个非割点 `v ≠ u` 满足 `r(G−v) = r−1`。
  证:`v ≠ a`(a 是割点),故 G−v 连通且 u 仍是叶。若 `r(G−v) ≥ r`,由极小性
  `t(G−v) ≥ 2r(G−v) ≥ 2r`,而 `t(G−v) ≤ t(G)`(诱导性遗传),与 G 是反例矛盾。
  故 `r(G−v) < r`,再由"半径至多降 1"(§5)得 `= r−1`。
- 令 `H = G−u`。删叶保持其余点间距离;叶 u 不是中心(其 `ecc = 1 + ecc(a) > r`),
  故 G 的中心都在 H 中,`r(H) ≤ r`;若 `r(H) < r`,u 是非割点,由"至多降 1"得 `r(H) = r−1`。
  于是 **`r(H) ∈ {r−1, r}`**。

**Case A:`r(H) = r−1`**(即删 u 也降半径)。此时每个非割点的删除都降半径,**G 是
vrd 图**(vertex-radius-decreasing),且有割点 a。由 vrd 结构定理(外部引用,§7):
`G = S_ℓ(B)`,ℓ ≥ 1,B 是 vrd 块,`r(G) = r(B) + ℓ`。记 `s = r(B)`。
- (论文)`s = 1`:B = K₂,`G = P_{2r}`,`t = 2r`,矛盾;
- (论文)`s ≥ 2`:B 中有 `2s−1` 个点的诱导路径 Q(ESS),Q 连同各点悬挂的 ℓ-长
  悬挂路构成诱导树,阶 ≥ `(2s−1)(ℓ+1) ≥ 2(s+ℓ) = 2r`,矛盾。
- **(§4 的简化:两条都不需要,一条测地线 + 一个更松的计数即可统一覆盖。)**

**Case B:`r(H) = r`**。
- H 无叶(否则 H 是更小的反例),故 **`δ(H) ≥ 2`**。
- **Claim 2**:H 的每个非割点 `v ≠ a` 满足 `r(H−v) = r−1`。
  证:G−v = (H−v) 加回叶 u,连通,故 v 也是 G 的非割点,由 Claim 1 `r(G−v) = r−1`;
  G−v 至少 3 个点,其叶 u 非中心,故 G−v 的中心都在 H−v 中,`r(H−v) ≤ r−1`;
  再由"至多降 1"取等。
- **Claim 3:H 无割点。** 反设,取端块 B₀,其唯一割点 c。由 δ(H) ≥ 2,B₀ ≠ K₂,
  故 c 在 B₀ 内至少两个邻点,可选 `v ≠ a`;v 是 H 的非割点且 `deg_H(v) ≥ 2`。
  由 Claim 2 + 下降判据**难半**(引用,§5):v 是 H 某中心点 z 的**唯一离心点(UEP)**。
  局部观察:UEP 且 deg ≥ 2 的点,其每个邻点都非割点
  (对邻点 x:另取邻点 y;`d(z,v) = r` 且 v 唯一 ⇒ `d(z,x) = r−1`;任何过 x 的
  z–q 测地线长 ≥ r > d(z,q),故 z 到其余点的测地线全避开 x ⇒ H−x 连通)。
  取 x = c 得 c 非割点,矛盾。
- 由 Claim 3,H 的点全是非割点。对每个 `v ≠ a`,Claim 2 + 难半给出中心点 `c_v`,
  其 UEP 是 v;不同 v 给出不同 `c_v`(一点至多一个 UEP)⇒ 至少 `n−1` 个中心。
- **Claim 4:H 自中心(self-centered)。** 若唯一可能的非中心点 b 存在,则其余点
  y 均满足 `d(y,b) ≤ ecc(y) = r`,故 `ecc(b) ≤ r`,又 `ecc(b) ≥ r`,得 b 中心,矛盾。
- 构造辅助图 D:`xy ∈ E(D) ⟺ d_H(x,y) = r`。自中心 ⇒ `δ(D) ≥ 1`;每个 `v ≠ a`
  有 1 度邻点 `c_v`(c_v 在 D 中只与 v 相邻,否则违反 UEP 唯一性)。由**辅助引理**
  (已形式化:`degree_one_neighbor_of_all_other`)⇒ a 也有 1 度邻点 c。
  于是 `d_H(c,a) = r` 且 a 是中心点 c 的 UEP。
- 由下降判据**易半**(自含,§5):`r(H−a) = r−1`。
- **有根 Chung 引理**(论文自证,§6(a)(b) 为需补的隐式步骤):H 连通、`r ≥ 2`、
  a 非割点、`r(H−a) = r−1` ⇒ H 有**含 a** 的诱导路径 P,`|P| ≥ 2r−1`。
- 放回叶 u:`G[V(P) ∪ {u}]` 仍是树(u 只与 a 相邻),阶 ≥ 2r。最终矛盾。∎

## 4. 复查发现 A:ESS/Chung 定理可以完全移除

论文在三处使用 ESS(`t ≥ 2r−1`):δ≥2 情形、Case A 的 `s ≥ 2` 分支、以及 Case A 的
`s = 1` 分类。**这三处都可以用更初等的论证替代:**

**观察 1(δ ≥ 2 情形).** 任何连通图有 `t ≥ diam + 1 ≥ r + 1`(测地线是诱导路)。
于是 `tδ ≥ 2(r+1) = 2r + 2 > 2r`。∎
不需要 ESS 的 `2r−1`;事实上 `t ≥ r` 就够了。

**观察 2(Case A 计数).** 结构定理给出 `G = S_ℓ(B)`、`r = s + ℓ`、`s = r(B) ≥ 1`。
在 B 中取一条测地线 Q(诱导路,`|Q| ≥ diam(B)+1 ≥ s+1`)。取 Q 的全部顶点加上
Q 各顶点悬挂的 ℓ-长悬挂路,得诱导树,阶 ≥ `(s+1)(ℓ+1)`,而

    (s+1)(ℓ+1) − 2(s+ℓ) = (s−1)(ℓ−1) ≥ 0   (s, ℓ ≥ 1)。∎

一条不等式统一覆盖 `s = 1` 与 `s ≥ 2`:
- 不再需要 ESS 给 B 里的 `2s−1` 诱导路;
- 不再需要"半径 1 的 vrd 图只有 K₂"这一分类引理;
- 取等情况恰是 `s = 1` 或 `ℓ = 1`(即 `P_{2r}` 与 `S₁` 族),与紧例吻合。

**影响.** 外部引用从 3 条降到 2 条(§5 难半 + §7 结构定理)。原计数
`(2s−1)(ℓ+1) ≥ 2(s+ℓ)`(Lean 中 `corona_tree_count`)可保留,但新的
`(s+1)(ℓ+1) ≥ 2(s+ℓ)` 更简单、假设更弱。建议采用简化路线,并回填论文
(§2.1 改为测地线论证、Case A 删去 K₂ 分类)。

## 5. 复查发现 B:下降判据拆两半,难半只用一次

论文的 Prop 2.2.1(半径下降判据)是:**v 非割点时,`r(G−v) < r(G)` ⟺ v 是某中心点
的 UEP;此时 `r(G−v) = r−1`。** 复查发现它应拆成不对称的两半:

**易半(自含,Phase 1 即可形式化).** 若 v 是中心点 c 的 UEP
(`d(c,v) = r = ecc(c)`,其余点 `d(c,x) ≤ r−1`),则:
- G−v 连通,且 c 到每个 x ≠ v 的测地线都避开 v——因为任何过 v 的 c–x 路
  长 ≥ `d(c,v) + d(v,x) ≥ r+1 > d(c,x)`;
- 故 `ecc_{G−v}(c) ≤ r−1`,`r(G−v) ≤ r−1`;
- 又"半径至多降 1"(下):取 G−v 的中心 c′,对 x ≠ v 有 `d_G(c′,x) ≤ d_{G−v}(c′,x) ≤ ρ`,
  而 `d_G(c′,v) ≤ 1 + ρ`(v 在 G−v 中有邻点 w),故 `r(G) ≤ ρ+1`。
- 合并:`r(G−v) = r−1`(且顺便证明 UEP 点必非割点)。

**难半(真正的外部引用).** v 非割点且 `r(G−v) = r−1 < r` ⇒ v 是某中心点的 UEP。
[Gliviak–Fajtlowicz;Swart 1996, Prop 2.2.1]

**论文中的使用位置:**
| 位置 | 需要什么 |
|---|---|
| Claim 1(`r(G−v) = r−1`) | 只有"至多降 1"(易) |
| `r(H) ∈ {r−1, r}` | 只有"至多降 1"(易) |
| Claim 2(`r(H−v) = r−1`) | 只有"至多降 1"(易) |
| Claim 3(⇒ v 是中心点的 UEP) | **难半**(唯一使用处) |
| 收尾(`r(H−a) = r−1`) | 易半 |

即:整个证明对判据的依赖集中在 Claim 3 的一个推论上。形式化时可以先做易半 +
"至多降 1",把难半作为独立的 Phase 2 目标。

## 6. 隐式步骤清单(形式化前必须补齐)

逐行复查论文证明,以下步骤在行文中被略过,形式化时必须显式化:

- **(a) 有根 Chung:`d(v₀,a) = r` 的"≤ r"方向。** 论文只写"其余点距 v₀ ≤ r−1 而
  r(F) = r"。补全:`≥ r` 由 `ecc_F(v₀) ≥ r(F)` 且其余点 ≤ r−1 强制;`≤ r` 由
  a 的任一邻点 w 满足 `d_F(v₀,w) ≤ r−1` 得 `d(v₀,a) ≤ 1 + (r−1)`。
- **(b) 有根 Chung:例外弦 `v₁–p₁` 出现时删 v₀ 仍 ≥ 2r−1。** 需要论证该弦迫使
  `d(v₀,w) = r−1`(总点数 2r):否则 `d(v₂,w) ≤ d(v₂,v₁) + 1 + d(p₁,w) = r−1 < r`,
  与 w 的取法矛盾。另外弦排除部分还需覆盖 `v₁–p_i (i ≥ 2)` 与 `v_j (j ≥ 2)–p_i`
  两类(前者由 `d(v₂,w) ≥ r` 排除,后者即 Chung 原弦论证)。
- **(c) Claim 3 的取块细节:** 端块存在性(块树的叶)、`B₀ ≠ K₂` 的论证
  (否则块内另一端点是 H 的叶,与 δ(H) ≥ 2 矛盾)、c 在 B₀ 内 ≥ 2 邻点
  (2-连通块的定义)、`v ≠ a` 可选(邻点 ≥ 2 个而 a 至多一个)、v 非割点
  (端块内非割点)。这些是标准块-割点引理,需逐条形式化。
- **(d) `c_v` 单射:** 一个点至多有一个 UEP(若 c 同时以 x、x′ 为 UEP,
  则 `d(c,x′) = ecc(c)` 与 UEP 定义中 `d(c,x′) < ecc(c)` 矛盾)。
- **(e) `|V(G)| ≥ 4`:** r ≥ 2 ⇒ 无泛在点 ⇒ n ≥ 3;n = 3 只有 P₃、K₃,半径均 1。
  (或:r ≥ 2 的连通图 n ≥ 4,最紧是 P₄。)
- **(f) a 是割点:** 删 a 后 u 孤立,需 `|V| ≥ 3`(由 r ≥ 2)。
- **(g) 删叶保距:** 删除叶 u 不改变其余点间距离(H 中距离 = G 中距离),
  由此得中心保留、ecc 不增等。
- **(h) 诱导性遗传:** `t(G−v) ≤ t(G)`(G−v 的诱导树也是 G 的诱导树)。
- **(i) 平凡界:** 连通非平凡图 `r ≥ 1`、`δ ≥ 1`;Case B 中 `r(H) = r ≥ 2` 用于
  有根 Chung 与"叶非中心"。
- **(j) Case A 的诱导树验证:** 在 `S_ℓ(B)` 中,Q 的顶点 + 相应悬挂路顶点的导出
  子图恰为树:新点只与自己悬挂路相邻(S_ℓ(B) 的构造),Q 在 B 中诱导。
