# Graffiti.pc #84：最终形式化证明导读

记有限连通非平凡简单图的半径为 r，最小度为 δ，最大诱导树的顶点数为 t。
目标是 **2r ≤ tδ**。最终声明为 `Graffiti84.graphConjecture84`。

背景与定位：Erdős–Saks–Sós（1986）已证明任意半径为 r 的连通图含有
至少 2r−1 个顶点的诱导路，即一般界 t ≥ 2r−1；δ≥2 的情形
（2r/δ ≤ r ≤ 2r−1 ≤ t）由此直接可得。本证明的核心新内容是叶子情形
δ=1 ⟹ t ≥ 2r（`Graffiti84.leafLemma`），即在有叶顶点时把该经典界
加强 1。形式化本身不依赖 ESS 定理：δ≥2 用初等测地线论证，叶子引理
从第一性原理证明。

## 1. 归约到有叶子的图

测地线诱导一条路，所以 t ≥ r+1。若 δ≥2，立即得到 2r≤tδ。
否则连通非平凡性保证 δ=1，只需证明叶子引理：有叶子时 t≥2r。

## 2. 删点半径与唯一离心点

UEP(c,v) 表示 v 是 c 的唯一离心点。对非平凡连通图：

- 如果删点图 G−v 的半径小于 r，则存在中心 c，使 UEP(c,v) 成立。
- 如果 c 是中心且 UEP(c,v)，则 G−v 的半径至多 r−1。

第二点中，从 c 到任意 x≠v 的最短路都避开 v，否则距离至少 r+1；
因此见证距离确实是删点图中的距离。
Lean 中 `radOn` 使用原图的限制距离，不能直接当作删点半径。
`Deletion.lean` 明确证明限制距离与实际诱导图之间的比较和所需等式。

## 3. Case A：所有非割点的删除都降低半径，且图有割点

`EndBlocks.lean` 的 UEP 闭包论证表明此时所有非割点都是叶子。
删去全部叶子，得到核心 H。半径至少 2 的情形中：

- H 连通，内部距离与 G 相同，r(G)=r(H)+1。
- H 的每个非割点在 G 中都有叶子邻点。
- H 仍具有“删除每个非割点都会降低半径”的性质。

这些结论在 `LeafCore.lean` 中证明。对顶点数归纳：
若 H 有割点，归纳给出 t(H)≥2r(H)。最大诱导树 T 至少包含 H 的两个非割点。
分别把它们在 G 中的叶子邻点加回，得到至少 t(H)+2≥2r(G) 个顶点的诱导树。
若 H 无割点，T 的每个顶点都有外部叶子邻点，加回这些不同叶子后得到
至少 2t(H)≥2(r(H)+1)=2r(G) 个顶点的诱导树。

这里使用的最大诱导树性质也有独立证明：若 T 的非割点 x 是原图割点，
T−x 位于 G−x 的一个分量；从另一个分量取 x 的邻点就能扩大 T，产生矛盾。
见 `MaximalTree.lean`。完整归纳为 `CaseA.vrd_cut_tree_bound`（命名空间为 `Graffiti84`）。
本路线不需要等长悬挂路图的完整结构分类。

## 4. Case B：唯一的例外删点

设连通图 H 的所有度数至少为 2，除指定顶点 a 外的每个非割点都满足删点降半径。
`deleteConnected_all_of_drop_except` 先证明所有顶点都是非割点。
于是每个 v≠a 都有中心 UEP 见证。

`CaseB.lean` 由这些见证证明 H 的每个顶点都是中心，并为 a 补出 UEP 见证。
使用 `RootedChung.lean` 中完整证明的有根诱导树构造，可得包含 a、
顶点数至少 2r(H)−1 的诱导树。给 a 接回原图的叶子，就达到 2r(H)。

## 5. 叶子引理的顶点数归纳

设存在反例 G，取叶子 u，其唯一邻点为 a。小半径情形由测地线界处理。
对每个非割点 v≠u，a 不会被删除（a 是割点），所以 G−v 仍连通并保留叶子 u。
归纳假设以及 t(G−v)≤t(G) 强迫 r(G−v)<r(G)。

令 H=G−u。删叶不增加半径：

- 若 r(H)<r(G)，所有非割点都满足删点降半径，且 a 是割点，应用 Case A。
- 若 r(H)=r(G)，H 不可能有叶子，否则直接用归纳假设。因此 H 的最小度至少为 2。
  H 的非割点 v≠a 在 G 中也非割；前段给出 G 中关于 v 的中心 UEP 见证。
  删叶保留距离且此时保留半径，故见证可转移到 H，得到 Case B 的条件。

两种情况都推出 t(G)≥2r(G)，与反例假设矛盾。
实际形式化采用强归纳，不依赖反例集合最小元的额外构造。
见 `LeafDeletion.lean` 和 `LeafLemma.lean`。
